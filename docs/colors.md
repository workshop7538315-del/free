# 色の役割 v0.1

各色には得意なことと苦手なことがあります。苦手を補うために他の色と組み合わせるのがデッキ構築の基本です。

## 白(W)

- **テーマ**:秩序、団結、守り
- **得意**:小型クリーチャーの展開、トークン生成、ライフ回復、クリーチャー除去(追放・タップ)、全体除去
- **苦手**:ドロー、大型クリーチャー
- **マナゾーンの個性**:マナが少ないほど得をする。「あなたのマナゾーンのカードが相手より少ないなら〜」

## 青(U)

- **テーマ**:知識、操作、変化
- **得意**:ドロー、打ち消し、バウンス(手札に戻す)、飛行
- **苦手**:パーマネントの破壊、ダメージ
- **マナゾーンの個性**:手札とマナゾーンの入れ替え。マナに置いたカードを手札に戻して使い直す

## 黒(B)

- **テーマ**:野心、死、代償
- **得意**:クリーチャー破壊、手札破壊、墓地からの回収、ライフを支払う効果
- **苦手**:アーティファクト・エンチャントへの対処
- **マナゾーンの個性**:墓地やマナゾーンからの再利用。マナゾーンのカードを墓地に送り、見返りを得る

## 赤(R)

- **テーマ**:衝動、自由、破壊
- **得意**:速攻、火力(ダメージ呪文)、アーティファクト破壊、一時的な強化
- **苦手**:長期戦、エンチャントへの対処
- **マナゾーンの個性**:マナを燃やして(墓地に置いて)爆発力を得る。後のことは考えない

## 緑(G)

- **テーマ**:自然、成長、力
- **得意**:大型クリーチャー、マナ加速、エンチャント・アーティファクト破壊、格闘(クリーチャー同士でダメージを与え合う)
- **苦手**:飛行クリーチャーへの対処、打ち消し
- **マナゾーンの個性**:追加チャージ、デッキの上からマナゾーンにカードを置く。マナゾーンの枚数を参照する

## 欠色(無色)

- **テーマ**:異質、虚無、どこにも属さない
- **得意**:どのデッキにも入る汎用カード、アーティファクト、{C}を要求する強力なカード
- **苦手**:色の個性に頼った強い効果は持たない
- **マナゾーンの個性**:無色マナ {C} を出す。相手のマナゾーンへの干渉(侵食)
- **デッキ構築上の役割**:色を濃くしたいデッキでは、マナに置いても色を出さない欠色カードは扱いにくい。代わりに {C} 指定の強力なカードを支える

## 多色

- **テーマ**:2色以上の組み合わせが持つ個性
- **得意**:単色では作れない強力な効果
- **代償**:コストに複数の色が必要。マナゾーンにはタップ状態で置かれる
- **マナゾーンの個性**:色の融通が利く。多色カードはどの色のマナでも出せるので、色の調整役になる

## 2色の組み合わせ(10組)

| 組み合わせ | テーマ案 |
|---|---|
| 白青 WU | 飛行、タップによる妨害 |
| 青黒 UB | 墓地とマナゾーンを行き来するコントロール |
| 黒赤 BR | 代償を払う攻撃的なデッキ |
| 赤緑 RG | 大型クリーチャーの速攻 |
| 緑白 GW | 横並びの展開と全体強化 |
| 白黒 WB | ライフの奪い合い |
| 青赤 UR | インスタント・ソーサリーを多用する |
| 黒緑 BG | 墓地とマナゾーンの再利用 |
| 赤白 RW | 小型クリーチャーで攻める |
| 緑青 GU | マナを大量に貯めて大技を使う |
