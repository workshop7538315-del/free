# スターターデッキのティア表

ティアの基準:**S**(環境トップ):60%以上、**A**(強い):54%以上、**B**(標準):46%以上、**C**(やや弱い):40%以上、**D**(弱い):40%未満

> CPU同士の対戦結果です。CPUが上手く扱えない仕組み(装備の付け替え、生け贄のタイミングなど)を持つデッキは、人間が使うと評価より強い可能性があります。
