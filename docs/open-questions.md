# 未決定事項・検討中の論点

## 1. 色の縛りの強さ

土地がないと、どのカードでもその色のマナになるため「全色入れれば色事故ゼロ」になりやすい。

- **A案(現在採用)**:MTG方式。{R}{R} のような色マナ記号はその色でしか払えない。色指定を重めにして単色寄りのデッキを有利にする。
- **B案**:デュエマ方式。「支払うマナの中に、そのカードの色のマナが最低1つ必要」で、残りは汎用。色の縛りはゆるい。
