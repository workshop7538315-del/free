# 未決定事項・検討中の論点

## 決定済み

- **色の指定方法**:MTG方式に決定。色マナ記号はその色のマナでしか払えない。カードの色はマナコストで決まる(→ [rules.md](rules.md) 5.4・5.5)。

## 1. 色マナ記号の重さの基準

MTG方式でも、マナゾーンにはどのカードでも置けるので色はそろえやすい。単色寄りのデッキが有利になるよう、強いカードほど {R}{R}{R} のように色マナ記号を多めにするか、テストプレイで確認する。

## 2. 初期手札とドロー枚数

チャージで手札が減るので、MTGより手札が枯れやすい。

- 初期手札 6枚か7枚か
- ドローを毎ターン1枚のままにするか
- 「チャージ時」能力を持つカードをどれくらい入れるかで調整する

## 3. 侵食(相手のマナを減らす効果)の扱い

土地破壊と同じく強力で、受ける側の体験が悪い。

- 欠色の専売特許にするか
- 1ターンに減らせる枚数の上限を設けるか

入れるかどうか未定。

## 5. 世界観・ゲーム名

## 6. 遊び方の想定

紙にプリントして遊ぶのか、設定資料として楽しむのか、デジタル化を目指すのか。カード書式や枚数の作り込み方に影響する。

## 7. カードのバランス

CPU同士の自動対戦(各400戦、`cd app && npm run simulate`)では、スターターデッキの勝率に30〜75%の差が出ている。白を含むデッキ(緑白・白黒)が強く、赤を含むデッキ(青赤・赤白・赤緑)が弱い。CPUの判断の癖も含んだ数字なので、人間同士のテストプレイと合わせて調整する。
