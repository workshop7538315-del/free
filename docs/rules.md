# 基本ルール v0.4

> 数値は仮置きです。テストプレイで調整します。

## 1. ゲームの準備

| 項目 | 値 | 備考 |
|---|---|---|
| プレイ人数 | 2人 | |
| デッキ枚数 | ちょうど40枚 | 土地がないので60枚より少なめ |
| 同名カード上限 | 4枚 | |
| 初期ライフ | 20 | |
| 初期手札 | 6枚 | マナに置く分を見込んで調整予定 |

1. 各プレイヤーはデッキをシャッフルし、6枚引く。
2. **マリガン**:1回だけ、手札をすべてデッキに戻してシャッフルし、6枚引き直せる。引き直した場合は手札から1枚を選んでデッキの一番下に置く。
3. 先攻・後攻を決める。先攻プレイヤーは最初のターンにドローしない。

## 2. 勝利条件

次のどれかを満たした相手プレイヤーは敗北する。

- ライフが0以下になった。
- 引くべきカードをデッキから引けなかった。
- カードの効果で敗北した。

## 3. 領域(ゾーン)

| 領域 | 公開/非公開 | 内容 |
|---|---|---|
| デッキ | 非公開 | 山札 |
| 手札 | 本人のみ | |
| マナゾーン | 公開 | マナとして置かれたカード。表向き |
| 戦場 | 公開 | クリーチャー、エンチャント、アーティファクト |
| 墓地 | 公開 | 破壊されたカード、使い終わった呪文 |
| 追放 | 公開 | ゲームから除外されたカード |
| スタック | 公開 | 解決待ちの呪文・能力 |

## 4. ターンの流れ

1. **アンタップ**:自分の戦場とマナゾーンのカードをすべてアンタップする。
2. **アップキープ**:「アップキープの開始時」に誘発する能力を解決する。
3. **ドロー**:カードを1枚引く。
4. **メイン1**
5. **戦闘**:攻撃宣言 → ブロック宣言 → 戦闘ダメージ
6. **メイン2**
7. **エンド**:「ターン終了時」の能力を解決し、ダメージが消える。手札が8枚以上なら7枚になるまで捨てる。

## 5. マナシステム

### 5.1 チャージ

- 自分のメインフェイズ中、**1ターンに1回**、手札のカードを1枚選んで表向きでマナゾーンに置ける。これを**チャージ**と呼ぶ。
- チャージは任意。スタックを使わず、優先権を持っていてスタックが空のときに行う。
- カードの効果でマナゾーンにカードが置かれても、チャージの回数には数えない。

### 5.2 マナを出す

マナゾーンのアンタップ状態のカードをタップすると、マナを1つ出す。

| マナゾーンのカード | 出せるマナ |
|---|---|
| 単色カード | その色のマナ1つ |
| 多色カード | そのカードが持つ色のうち、好きな1色のマナ1つ |
| 欠色(無色)カード | 無色マナ {C} 1つ |

### 5.3 多色カードのタップイン

- 多色カードは**タップ状態でマナゾーンに置かれる**。置いたターンにはマナとして使えない。

### 5.4 コストの表記と払い方(MTG方式)

コストはMTGと同じ表記を使う。色マナ記号はその色のマナでしか払えない。

| 記号 | 意味 | 払えるマナ | マナ総量への加算 |
|---|---|---|---|
| {W}{U}{B}{R}{G} | 色マナ | その色のマナのみ | 1 |
| {1}{2}{3}… | 汎用マナ | どの色・無色マナでもよい | その数 |
| {C} | 無色マナ指定 | 無色マナのみ | 1 |
| {W/U} など | 混成マナ | 2色のどちらか一方のマナ | 1 |
| {2/W} など | 単色混成マナ | その色のマナ1つ、または任意のマナ2つ | 2 |
| {X} | 唱えるときに決める数 | 汎用マナと同じ | 0(スタック上以外) |

例:
- {2}{R}{R} = 赤マナ2つ + 任意のマナ2つ(マナ総量4)
- {R/W}{R/W} = 赤か白のマナを2つ。赤2つ、白2つ、赤1つ白1つのどれでもよい(マナ総量2)

### 5.5 カードの色

カードの色は、MTGと同じくマナコストに含まれる色マナ記号で決まる。

| マナコスト | カードの色 | 例 |
|---|---|---|
| 色マナ記号が1色だけ | その色の単色 | {2}{R}{R} → 赤 |
| 色マナ記号が2色以上 | 多色(含まれる色すべて) | {1}{W}{U} → 白青 |
| 混成マナ記号 | 記号に含まれる色すべて | {R/W} → 赤白の多色 |
| 色マナ記号なし({C}・汎用のみ) | 欠色(無色) | {3}、{4}{C} → 欠色 |

- 混成マナを含むカードも多色カードなので、マナゾーンにはタップ状態で置かれる。

## 6. カードタイプ

| タイプ | 使えるタイミング | 説明 |
|---|---|---|
| クリーチャー | 自分のメイン、スタックが空 | パワー/タフネスを持つ。戦場に出たターンは攻撃できない(召喚酔い) |
| インスタント | いつでも | 解決後は墓地へ |
| ソーサリー | 自分のメイン、スタックが空 | 解決後は墓地へ |
| エンチャント | 自分のメイン、スタックが空 | 戦場に残り、効果を発揮し続ける |
| アーティファクト | 自分のメイン、スタックが空 | 戦場に残る。欠色であることが多い |

## 7. 戦闘

MTGに準拠する。

1. **攻撃宣言**:アクティブプレイヤーは、召喚酔いしていないアンタップ状態のクリーチャーを好きな数だけタップして攻撃させる。攻撃先は相手プレイヤー。
2. **ブロック宣言**:防御側は、アンタップ状態のクリーチャーで攻撃クリーチャーをブロックできる。1体で1体をブロックし、1体の攻撃クリーチャーを複数でブロックしてもよい。
3. **戦闘ダメージ**:クリーチャーは同時にパワー分のダメージを与える。ブロックされなかったクリーチャーは防御側プレイヤーにダメージを与える。
4. タフネス以上のダメージを受けたクリーチャーは破壊される。

## 8. マナゾーンに関する基本ルール

- マナゾーンのカードは、カードの能力を持たない「マナ源」として扱う。ただし [keywords.md](keywords.md) のキーワードのように、マナゾーンで働くと明記された能力は例外。
- マナゾーンのカードは戦場のカードではない。「パーマネントを破壊する」効果の対象にならない。
- マナゾーンの枚数に上限はない。

## 9. 追加のルール

### 9.1 装備品
- 装備品はアーティファクト。装備コストを払い、自分のメインフェイズ(スタックが空のとき)に自分のクリーチャー1体につける。
- 装備しているクリーチャーが戦場を離れても、装備品は戦場に残る(何にもついていない状態になる)。
- 別のクリーチャーに付け替えるときも、装備コストを払う。

### 9.2 コストが変わる能力
- **共鳴**や「〜のコストは{1}少なくなる」は、汎用マナの部分だけを減らす。色マナ記号は減らない。
- **零式**の条件を満たしていれば、マナを払わずに唱えてよい(タイミングのルールは変わらない)。
- **追加払い**は、元のコストに追加払いのコストを足して払う。
- **再演**で唱えたカードは、解決したあとや打ち消されたあとに追放される。

### 9.3 循環
- 手札にある循環コストを持つカードは、優先権があればいつでも、コストを払って捨て、カードを1枚引ける。

### 9.4 孤高(ハイランダー)
- 対戦開始時のデッキに同じ名前のカードが2枚以上入っていないなら、そのプレイヤーは対戦中ずっと「孤高」の条件を満たす。

### 9.5 強化版・派生版のキーワード
- **鉄壁**を持つクリーチャーは、攻撃クリーチャーを何体でもブロックできる。ブロックしたそれぞれにパワー分のダメージを与え、それぞれからダメージを受ける。
- **大威迫**は3体以上、**威迫**は2体以上でブロックしないとブロックにならない。
- **疾駆**で唱えたクリーチャーは速攻を得て、そのコントローラーの終了ステップの開始時に手札に戻る。
- **輪廻**は、死亡して墓地に置かれたあと、マナゾーンに移る。トークンには働かない。不屈と両方持つなら不屈が先に働く。
- **烈燃 N**は、唱えるときに燃焼する枚数(0〜N)を決める。燃焼した枚数は「X」として効果で使う。
- **略奪**で移したカードは、移した側のものになる(持ち主も変わる)。

### 9.6 紋章と顕現(第4弾)
- **紋章**の能力は、そのカードがコントローラーのマナゾーンにあるあいだだけ働く。戦場に出ているあいだは働かない。逆に、紋章でない能力はマナゾーンでは働かない(8章の原則どおり)。
- 紋章を持つカードがマナゾーンからタップされても、紋章は働き続ける。マナゾーンを離れると働かなくなる。
- **顕現 N**は、解決時に自分のマナゾーンからマナ総量N以下のクリーチャー・カードを1枚選んで戦場に出す(出せるカードがあれば必ず出す)。戦場に出たカードはマナゾーンから離れるので、マナが1つ減る。
- 顕現で出したクリーチャーは召喚酔いの影響を受ける(「速攻を得る」と書かれていれば攻撃できる)。
