# キーワード能力 v0.1

> デッキビルダーのツールチップとキーワード絞り込みは [`cards/keywords.json`](../cards/keywords.json) を読んでいます。キーワードを追加・変更するときは、このページと keywords.json の両方を更新してください。

## このゲーム独自のキーワード

マナゾーンを中心にしたキーワードです。「マナに置いても損しない」「マナゾーンが第2の手札になる」といった体験を作ります。

### チャージ時

> **チャージ時** ― (効果)
> このカードがマナゾーンに置かれたとき、(効果)を得る。

- チャージだけでなく、カードの効果でマナゾーンに置かれたときにも誘発する。
- 例:「チャージ時 ― カードを1枚引く。」
- 主な色:全色(色ごとに効果の傾向が違う)

### マナ解放 {コスト}

> **マナ解放 {コスト}**
> このカードがマナゾーンにあるなら、マナ解放コストを支払ってマナゾーンから唱えてもよい。

- 唱えるときに、このカード自体をタップしてマナに使うことはできない。
- 主な色:緑、青

### 還元

> **還元を行う**
> 自分のマナゾーンのカードを1枚選び、手札に戻す。

- 能力として起動するのではなく、他のカードのコストや効果で使う動詞。
- 例:「戦場に出たとき、還元を行ってもよい。そうしたなら、カードを2枚引く。」
- 主な色:青、黒

### 燃焼 N

> **燃焼 N**
> このカードを唱えるための追加コストとして、自分のマナゾーンのカードをN枚墓地に置いてもよい。

- 燃焼したかどうかで効果が変わる。
- 例:「燃焼 2(燃焼したなら、このクリーチャーは速攻を得る。)」
- 主な色:赤、黒

### 侵食 N

> **侵食 N**
> 対戦相手のマナゾーンのカードをN枚選び、持ち主の墓地に置く。

- 土地破壊と同じく、使われる側のストレスが大きい。コストは重めに設定する。
- 主な色:欠色

### 開花

> **開花** ― (効果)
> 自分のマナゾーンのカードが7枚以上あるなら、(効果)を得る。

- 主な色:緑、多色(緑を含む)

## MTGから流用する基本キーワード

| キーワード | 効果 | 主な色 |
|---|---|---|
| 飛行 | 飛行か到達を持つクリーチャーでしかブロックできない | 白、青 |
| 到達 | 飛行を持つクリーチャーをブロックできる | 緑 |
| 速攻 | 召喚酔いしない | 赤 |
| 先制攻撃 | 通常より先に戦闘ダメージを与える | 白、赤 |
| 接死 | 1点でもダメージを与えたクリーチャーを破壊する | 黒、緑 |
| 絆魂 | 与えたダメージ分ライフを得る | 白、黒 |
| トランプル | ブロックしたクリーチャーのタフネスを超えたダメージをプレイヤーに与える | 緑、赤 |
| 警戒 | 攻撃してもタップしない | 白、緑 |
| 呪禁 | 対戦相手の呪文や能力の対象にならない | 緑、青 |
| 瞬速 | インスタントのタイミングで唱えられる | 青 |
