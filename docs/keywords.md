# キーワード能力 v0.3

> デッキビルダーのツールチップとキーワード絞り込みは [`cards/keywords.json`](../cards/keywords.json) を読んでいます。キーワードを追加・変更するときは、このページと keywords.json の両方を更新してください。

## このゲーム独自のキーワード

マナゾーンを中心にしたキーワードです。「マナに置いても損しない」「マナゾーンが第2の手札になる」といった体験を作ります。

### チャージ時

> **チャージ時** ― (効果)
> このカードがマナゾーンに置かれたとき、(効果)を得る。

- チャージだけでなく、カードの効果でマナゾーンに置かれたときにも誘発する。
- ただし、**チャージ時の能力によってマナゾーンに置かれたカードのチャージ時は誘発しない**(連鎖しない)。
- 例:「チャージ時 ― カードを1枚引く。」
- 主な色:全色(色ごとに効果の傾向が違う)

### マナ解放 {コスト}

> **マナ解放 {コスト}**
> このカードがマナゾーンにあるなら、マナ解放コストを支払ってマナゾーンから唱えてもよい。

- 唱えるときに、このカード自体をタップしてマナに使うことはできない。
- 主な色:緑、青

### 還元

> **還元を行う**
> 自分のマナゾーンのカードを1枚選び、手札に戻す。

- 能力として起動するのではなく、他のカードのコストや効果で使う動詞。
- 例:「戦場に出たとき、還元を行ってもよい。そうしたなら、カードを2枚引く。」
- 主な色:青、黒

### 燃焼 N

> **燃焼 N**
> このカードを唱えるための追加コストとして、自分のマナゾーンのカードをN枚墓地に置いてもよい。

- 燃焼したかどうかで効果が変わる。
- 例:「燃焼 2(燃焼したなら、このクリーチャーは速攻を得る。)」
- 主な色:赤、黒

### 侵食 N

> **侵食 N**
> 対戦相手のマナゾーンのカードをN枚選び、持ち主の墓地に置く。

- 土地破壊と同じく、使われる側のストレスが大きい。コストは重めに設定する。
- 主な色:欠色

### 開花

> **開花** ― (効果)
> 自分のマナゾーンのカードが7枚以上あるなら、(効果)を得る。

- 主な色:緑、多色(緑を含む)

## 拡張で追加したキーワード

カードを500種類に増やしたときに追加したキーワードです。参考にしたゲームの仕組みと、このゲームでの役割を書いています。

### 条件のキーワード(「― 」のあとの効果が条件つきで有効になる)

| キーワード | 条件 | 参考 | 主な色・テーマ |
|---|---|---|---|
| マナ武装 N(色) | 自分のマナゾーンにその色のカードがN枚以上 | デュエル・マスターズのマナ武装 | 全色。単色デッキ向け |
| 孤高 | 自分のデッキに同じ名前のカードが2枚以上入っていない | ハイランダー構築 | 全色 |
| 深淵 | 自分の墓地にカードが7枚以上 | MTGのスレッショルド | 黒・青・緑 |
| 背水 | 自分の手札が0枚 | MTGの暴勇 | 黒・赤 |
| 機巧 | アーティファクトを3つ以上コントロール | MTGの金属術 | 「鉄機」 |
| 獰猛 | パワー4以上のクリーチャーをコントロール | MTGの獰猛 | 緑 |

### 誘発のキーワード

| キーワード | いつ | 参考 |
|---|---|---|
| 鼓動 | 自分のマナゾーンにカードが置かれるたび(チャージでも効果でも) | MTGの上陸。このゲームでは土地の代わりにマナゾーン |

### 唱え方・コストのキーワード

| キーワード | 効果 | 参考 |
|---|---|---|
| 追加払い {コスト} | 唱えるときに追加で払ってもよい。払うと「追加払いしたなら」の効果が出る | MTGのキッカー |
| 再演 {コスト} | 墓地から再演コストで唱えられる。唱えたあとは追放 | MTGのフラッシュバック |
| 循環 {コスト} | 手札から循環コストを払って捨て、1枚引く | MTGのサイクリング |
| 共鳴(〜) | 〜を1つコントロールするごとにコストが{1}少なくなる | MTGの親和、デュエマのシンパシー |
| 零式(条件) | 条件を満たしていればマナを払わずに唱えてもよい | デュエマのG・ゼロ |
| 装備 {コスト} | 自分のメインフェイズに、自分のクリーチャー1体につける。クリーチャーがいなくなっても装備品は残る | MTGの装備 |

### 基本キーワードの追加

| キーワード | 効果 |
|---|---|
| 二段攻撃 | 先制攻撃のダメージと通常のダメージの両方を与える |
| 破壊不能 | 破壊されず、致死ダメージでも死亡しない |
| 不屈 | +1/+1カウンターが置かれていない状態で死亡したら、カウンター1個を置いて戦場に戻る |

## 強化版・派生版のキーワード

既存のキーワードを強くしたもの(強化版)と、形を変えたもの(派生版)です。カードは `cards/sets/advanced.mjs` にあり、アーキタイプ「派生キーワード」で絞り込めます。

| 元のキーワード | 新しいキーワード | 種類 | 効果 |
|---|---|---|---|
| 飛行 | **天翔** | 強化 | 天翔を持つクリーチャーでしかブロックされない。飛行や到達でも止められない |
| 威迫 | **大威迫** | 強化 | 3体以上のクリーチャーでしかブロックされない |
| 絆魂 | **吸血** | 派生 | ダメージを与えるたび、自分の上に+1/+1カウンターを1個置く。ライフの代わりに自分が育つ |
| 速攻 | **疾駆 {コスト}** | 派生 | 疾駆コストで唱えると速攻を得る。その代わり、終了ステップに手札に戻る |
| 防衛 | **鉄壁** | 派生 | 攻撃クリーチャーを何体でもブロックできる |
| 不屈 | **輪廻** | 派生 | 死亡すると、墓地ではなくマナゾーンに置かれる(鼓動も誘発する) |
| 燃焼 N | **烈燃 N** | 強化 | マナゾーンのカードを0〜N枚の好きな枚数だけ燃焼でき、燃焼した枚数(X)だけ効果が大きくなる |
| 侵食 N | **略奪 N** | 派生 | 相手のマナゾーンのカードをN枚、**裏向き(欠色)**にしてタップ状態で自分のマナゾーンに移す。相手のマナが減るので、9マナ以上の大型だけが持つ(第7弾で変更) |
| 開花 | **満開** | 強化 | 自分のマナゾーンが10枚以上なら有効 |
| 深淵 | **奈落** | 強化 | 自分の墓地が12枚以上なら有効 |
| 瞬速 | **伏兵** | 派生 | 相手のターンに戦場に出たときだけ追加の効果が出る |

## 第4弾のキーワード

| キーワード | 効果 |
|---|---|
| **紋章 ―** | このカードがマナゾーンにあるあいだだけ働く能力。戦場・手札・墓地では働かない |
| **顕現 N** | あなたのマナゾーンにあるマナ総量N以下のクリーチャー・カードを1枚選び、戦場に出す |

紋章を持つカードは「あなたのマナゾーンにある紋章を持つカードの枚数」で強くなるカードにも数えられます。

## 第6弾のキーワード

| キーワード | 効果 |
|---|---|
| **決闘** | あなたのクリーチャーと対戦相手のクリーチャーが、互いに自身のパワーに等しいダメージを与え合う。先制攻撃(二段攻撃)を持つ側だけが先にダメージを与え、それで倒れた側はダメージを返せない。相手のクリーチャーだけが致死ダメージを負ったら「決闘に勝った」ことになる |
| **陰謀 ―** | このターン、対戦相手がカードを捨てたか、対戦相手のクリーチャーが戦場を離れた(死亡・手札に戻る・追放・生け贄など)なら、― のあとが有効になる |

「あなたが決闘に勝つたび」に誘発する能力もあります。種族**貴族**は各色にいて、白・黒・多色の貴族が他の貴族を強くします。

## 第7弾のキーワード

| キーワード | 効果 |
|---|---|
| **虚無** | 種族・呪文の種類。コストに {C}(欠色マナでしか払えない記号。画面では「◇」)を持ち、欠色マナがなければ唱えられない |
| **嚥下 N** | 対戦相手のライブラリーの一番上からN枚を、裏向き(欠色)でタップ状態のまま自分のマナゾーンに置く。相手のマナは減らない(エルドラージの嚥下が元) |
| **虚食** | この呪文のコストは、自分のマナゾーンの裏向きのカード1枚につき{1}少なくなる({C}は減らない) |
| **虚化 N** | あなたのマナゾーンにある表向きのカードをN枚と、対戦相手のマナゾーンにある表向きのカードをN枚、あなたが選んで裏向きにする |
| **虚空 ―** | あなたのマナゾーンのカードの半分以上が欠色(裏向きを含む)なら有効 |
| **真空 ―** | あなたのマナゾーンのカードがすべて欠色(裏向きを含む)で、1枚以上あるなら有効 |

**裏向きのカード**は、名前・色・能力を持たない欠色のカードとして扱い、欠色マナ({C})を1つ出します。紋章やマナ解放も働きません。マナゾーンを離れると表向きに戻ります。略奪・嚥下で奪ったカードも裏向きになります。

**始祖**(13〜15マナの大型の虚無)は「唱えたとき」に略奪します。打ち消されても失われません。また「どこからでも墓地に置かれたとき、墓地をライブラリーに戻して切り直す」ので、墓地から戻して踏み倒すことはできません。**落とし子**トークン(0/1)は、生け贄に捧げると欠色マナ({C})を1つ出します。

## 名前を参照するテーマ

カード名で互いを参照するテーマ(遊戯王の「〜」と名のついたカード)は、**2つまで**にしています。

| テーマ | 色 | 内容 |
|---|---|---|
| 「星詠み」 | 白青 | 「星詠み」のカードを探す・出すたびに引く・強化する |
| 「鉄機」 | 欠色+赤 | アーティファクトを並べて機巧と共鳴で押す |

## MTGから流用する基本キーワード

| キーワード | 効果 | 主な色 |
|---|---|---|
| 飛行 | 飛行か到達を持つクリーチャーでしかブロックできない | 白、青 |
| 到達 | 飛行を持つクリーチャーをブロックできる | 緑 |
| 速攻 | 召喚酔いしない | 赤 |
| 先制攻撃 | 通常より先に戦闘ダメージを与える | 白、赤 |
| 接死 | 1点でもダメージを与えたクリーチャーを破壊する | 黒、緑 |
| 絆魂 | 与えたダメージ分ライフを得る | 白、黒 |
| トランプル | ブロックしたクリーチャーのタフネスを超えたダメージをプレイヤーに与える | 緑、赤 |
| 警戒 | 攻撃してもタップしない | 白、緑 |
| 呪禁 | 対戦相手の呪文や能力の対象にならない | 緑、青 |
| 瞬速 | インスタントのタイミングで唱えられる | 青 |
| 防衛 | 攻撃できない | 白、欠色 |
| 威迫 | 2体以上のクリーチャーでしかブロックされない | 黒 |
