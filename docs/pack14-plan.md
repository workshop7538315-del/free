# 第14弾「狐火の社と百鬼夜行」

紋章・墓地などを強くしたいアーキタイプ向けの、ユーザーの案(狐火・百鬼)をもとに作ったパック。28種類と、生成専用の《狐火 / 走る焔》《銀白の巫女 ミナモ》(加護から出るもの)。

## 狐火(欠色・紋章・墓地)

- 狐火のインスタント(両面カード4種):《揺蕩う狐火 / 純白の妖狐 ミナモ》《煌めく狐火 / 銀白の巫女 ミナモ》《囁く狐火 / 宵闇の妖狐 シグレ》《弾ける狐火 / 焔尾の妖狐 アカネ》。表はインスタント─狐火、裏は伝説のクリーチャー─妖狐。
- 狐火を生成するカード(3種):《狐の嫁入り》《稲荷の社》《白狐の使い》。
- 稲荷の紋章を持つ狐火をマナゾーンのカードに重ねるほど、マナ総量5以上のインスタントが{2}ずつ軽くなる。コストが0になれば**開顕**で裏面の妖狐を出せる。
- 《純白の妖狐 ミナモ》(《顕現の潮巫女 ミナモ》のリメイク)はライブラリーを狐火だけにして、狐火を使うたびに《走る焔》を速攻で出す。決まれば勝ち、外せばライブラリー切れで負ける大技(上限なし)。CPUは、ライブラリーの狐火で削りきれそうなときだけ開顕する。

### ユーザーと決めたこと
- 狐火を重ねたマナゾーンのカードはマナを出せない。
- 狐火 / 走る焔は表がインスタントの狐火、裏が走る焔。墓地に行かず、生成以外で出せず、デッキに入れられない。
- 妖狐のクリーチャーは伝説(走る焔は除く)。伝説は名前で判定。
- 《ミナモの加護》から出る《銀白の巫女 ミナモ》は新しく生成したもの。カウントが減るのは狐火をインスタントとして使ったときだけ。
- 「山札に戻す」はライブラリーを切り直す意味。

## 百鬼(黒緑+マナ総量100・クリーチャーだけ・セルフランデス・手札なし・紋章)

- マナ総量100の百鬼5体:《百鬼の魁 金剛羅刹》《百鬼の幽姫 百々目》《百鬼の一番槍》《百鬼の大天狗》《百鬼の大酒呑み 酒呑》。手札にほかのカードがないときに**百鬼顕現**で、マナゾーンか手札から出す。払ったマナゾーンのカードは墓地へ。
- 《金剛羅刹》が百鬼顕現で出ると、墓地の百鬼が**百鬼夜行**を得る。そのターンにマナゾーンから墓地に落ちた百鬼は、ターン終了時に戻ってきて全体+2/+1。
- 支え(黒緑のクリーチャー11種):手札をマナに置く《百鬼の小鬼》《付喪神の行列》《輪入道》、百鬼をマナに探す《鬼火の案内人》、百鬼顕現を軽くする《ぬらりひょん》など。

### ユーザーと決めたこと
- 百鬼夜行の条件は「ターン終了時に、このターンこのカードがマナから墓地に送られていたら」。
- 金剛羅刹の追加ターンは1ゲームに1回。

## 調整(ほかの全デッキと各8戦、392戦)

| デッキ | 最初 | 最後 |
|---|---|---|
| 狐火:稲荷の社(欠色) | 21.9% | 51.0% |
| 百鬼:百鬼夜行(黒緑) | 11.5% | 57.1% |

- 百鬼:素のパワーは案のとおり0(0/12・0/8・0/10)。百鬼夜行の+2/+1で上がる。百々目と一番槍の能力は「どこからでも墓地に置かれたとき」で、手札がないときの効果(自分をマナに置く・相手のパーマネントを破壊)も「してもよい」にした。百鬼顕現は羅刹6・百々目4・一番槍5。百々目は接死と「出たとき相手のクリーチャー1体を破壊」を持つ。
- 百鬼顕現で出たクリーチャーは+2/-2され、次の対戦相手のターンの終了時に墓地に置かれる(ユーザーの変更)。墓地に置かれたときの能力や百鬼夜行とつながる。57.1%になったので、羅刹の百鬼顕現を6に戻して54.3%。
- 金剛羅刹の効果は、追加ターンだけ任意(百鬼夜行を与える・紋章で引いたカードを捨てるのは強制)。百鬼顕現で出たクリーチャーは速攻も得る(出たターンに殴って、次の相手ターンの終了時に墓地へ)。
- マナ総量100の百鬼を2種追加(ユーザーの要望):《百鬼の大天狗》(0/9 飛行、紋章:百鬼顕現{1}軽く、百鬼顕現6で相手のクリーチャー1体を手札に戻す。墓地に置かれたとき、手札のクリーチャーをマナに置いてもよい/手札がなければライブラリーの一番上をマナに置いてもよい)、《百鬼の大酒呑み 酒呑》(0/11 トランプル、百鬼顕現6。墓地に置かれたとき、手札のクリーチャーをマナに置いてもよい/手札がなければ各クリーチャーにそれぞれ2点を与えてもよい)。
- 追加と速攻で67.1%になったので、酒呑のダメージを4→2、大天狗のマナを2枚→1枚・百鬼顕現5→6、ぬらりひょんの戦場での軽減を{2}→{1}、支えの体を戻し(小鬼2/1、鎌鼬2/1、輪入道4/3)、スターターの大天狗・酒呑を1枚ずつにして56.1%。
- 酒呑の手札がないときの効果を「各クリーチャーにそれぞれ2点」に(ユーザーの変更。CPUは相手が失うものが大きいときだけ使う)。57.1%。
- 百鬼:CPUは、金剛羅刹を呼べるならほかの百鬼をマナに残し、羅刹の支払いでマナの百鬼を優先して墓地に落とす(百鬼夜行でまとめて戻る)。マナから落ちたこのターンに羅刹がいれば、百々目はマナに戻さない。支えの体を少し大きく(小鬼2/2、山童2/3、鎌鼬3/1、輪入道5/3)。パワー0で18%→これらで51.3%。
- 狐火:生成した狐火がライブラリーで腐るので、《狐火 / 走る焔》の表に「カードを1枚引く」を足した。《揺蕩う狐火》は見る枚数を3枚に、《囁く狐火》のドローを2枚に、《弾ける狐火》を5点・クリーチャーかプレイヤーに。《狐の嫁入り》は{3}で1枚引く、《稲荷の社》は{2}で1枚引く。CPUは狐火のインスタントをチャージしにくくした。
