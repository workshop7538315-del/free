# 第15弾「Stella Facet」

韓国をモチーフにした、アイドル+ソシャゲのパック(ユーザーの案 PACK15_PLAN.md をもとに制作)。42種類と、生成専用の練習生3種・《おやすみなさい…》。スターターはグループ(白青赤)1種。ソロ3種はこのあと新規カード込みで作る。

設計思想:「トークンはプレイヤーが好きなように選べるカード。プレイヤーがスカウトした原石を磨き上げ、トップアイドルにする」。

## 流れ

1. **オーディション**で練習生(トークン)を得る
2. **プロデュース**で、秘蔵庫のレッスン(両面の装備品)を練習生につける
3. 条件を満たすとレッスンが裏返って練習生に重なり、練習生は名前のついたアイドルになる
4. アイドルの組み合わせで**グループ活動**が働く
5. 切札《フィナーレ・シャイン》

## ルール(ユーザーと決めたこと)

- **伝説は名前で判定**。《躍る星 ミニー》と《ごちそうさまでした! ミニー》は別の名前なので並べられる。練習生がもう《躍る星 ミニー》になっていても、新しい練習生を出してよく、その子が《ごちそうさまでした! ミニー》になれば2人並ぶ。
- 《躍る星 ミニー》につけたレッスンが裏返ったときは、上に**重なる**(上の面が名前・パワー・タフネス、下の面の能力も加わる)。
- **レッスンのマナコストは低め**({R}〜{1}{R})。色は一応ある。プロデュースはコストを払い、指定タイプのカードを1枚捨てる。
- **装備はどのクリーチャーにもできる**が、担当の合う練習生(かその練習生がなったアイドル)についていないと裏返らない。
- 練習生は2/2のトークン。色は担当の色(ダンス=赤、ボーカル=青、ビジュアル=白)。
- 裏返ったレッスンはクリーチャーの下に重なり、クリーチャーが戦場を離れると秘蔵庫に戻る(またプロデュースできる)。
- 裏返ったときは、裏面の「戦場に出たとき」も誘発する。

- **練習生は担当ごとに場に1体まで**(アイドルになった子は数えない)。オーディションは、まだ場にいない練習生になれるカードが出るまでめくる。出せないことが確定しているとき(3人そろっている、ライブラリーに新しい練習生になれるカードがない)は、代わりに1枚引く。めくったカードはライブラリーに戻して切り直す。2つの担当になれるカードは、場にないほうになる。
- **裏方**:欠色の共通カード(プロデューサーのカード)8種は、プロデュースで指定のタイプでなくても捨ててよい。

## こちらで決めたこと

- 「毎ターン攻撃する前に決闘する」(アピールの基本)は、「装備しているクリーチャーが攻撃するたび、対戦相手のクリーチャー1体と決闘する」(強制)。
- 裏返りの条件のうち「このターンに」とあるもの(黄金・2枚目のドロー・6点のライフ)は、つける前にそのターンに満たしていてもよい。ほかの条件(決闘に勝つ・打ち消すか手札に戻す・戦闘ダメージ)は、つけたあとに起きたものだけ。
- 体型の設定はカードの文章・フレーバーに入れない(性格・趣味・担当でキャラを出す)。
- 共通・支援カードは、能力が無色のもの(オーディション系)を多めにし、3色でも動けるようにした。

## 調整(グループのスターター、ほかの全デッキと各8戦)

最初は17%。手札が尽きる・練習生がすぐ倒れる・アイドルになりにくいのが原因だった。
- 練習生を2/2に、基本のレッスンの修整を大きく(アピール+2/+1、目線+2/+2)、アイドルの体を+1/+1。
- 《三人のステージ》に「アップキープにオーディション」、《三人分の楽譜》に1枚引く、《運命のオーディション》を{2}に、《事務所の看板猫》を2/2に。
- 《フィナーレ・シャイン》に「オーディションを2回、全体+1/+1」を足し、グループ活動 Vo+Da+Vi で相手を全部タップして+2/+2・トランプル。
- CPU:プロデュースで裏返りに使うカード(手札に戻す・打ち消す・黄金・オーディション)を捨てない。裏返りを待っているレッスンがあるときは、それを満たす呪文を優先する。
- 最終 **57.8%**(400戦)。
- 練習生を担当ごとに1体まで・裏方を入れたあとは **52.5%**(400戦)。CPUは裏方のカードを先に捨てる。

## 山と資産運用(あとから追加)

- 《黄金》などの資源トークンは、場で1つの**山**に重なる(×5のように数で持つ)。《黄金》は生成すると直接場に置かれる。
- **資産運用 N**:《黄金》をN個使ってもよい。使ったなら追加の効果。《凛として、優雅に》(1枚引く)、《セラのティーセット》(オーディション)が持つ。
