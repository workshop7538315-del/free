## スターターデッキ

`cards/build.mjs` が自動で組みます。テーマのセットのカードを優先し、残りを除去とクリーチャーで埋めます。テーマデッキには、自分のクリーチャーも巻き込む全体除去は入れません。

| デッキ | 色 |
|---|---|
| 2色の汎用デッキ×10 | 2色の組み合わせすべて(最初の166種類が中心) |
| 人間:民衆の蜂起 | 白赤 |
| エンチャント:星座の祝福 | 緑白 |
| マナ総量3:三刻の盟約 | 白青+欠色 |
| 孤高:三色の独唱 | 黒赤緑(40種類すべて1枚ずつ) |
| 星詠み:天球の導き | 白青 |
| 鉄機:鋼の軍団 | 赤+欠色 |
| 墓地:深淵の書庫 | 青黒 |
| 生け贄:血の宴 | 黒赤 |
| ライフ:命の循環 | 白黒 |
| カウンター:不屈の大地 | 黒緑 |
| 呪文:嵐の詠唱 | 青赤 |
| 装備:武具の行進 | 赤白 |
| 鼓動:大地の脈動 | 赤緑 |
| マナ武装:赤単の烈火 / 緑単の巨獣 | 赤 / 緑 |
