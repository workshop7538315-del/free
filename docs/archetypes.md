# アーキタイプ一覧

カード500種類の中にある、デッキ構築の方向性(アーキタイプ)です。デッキビルダーの「アーキタイプ」で絞り込めます。対戦の「スターターデッキ」には、各アーキタイプのデッキがあります。

| アーキタイプ | 色 | 狙い | 代表的なカード | 参考 |
|---|---|---|---|---|
| 人間 | 白中心(赤・緑・青・黒) | 人間を並べ、人間の数で強くなる。共鳴(人間)や零式で展開を速くする | 民衆の指導者、聖堂騎士団長、蜂起 | MTGの部族、デュエマのシンパシー |
| エンチャント | 緑白(青・黒) | オーラやエンチャント・クリーチャーを出し、「エンチャントが出るたび」で得をする | 聖域の結界、星座の牡鹿、森の女神 | MTGの星座 |
| マナ総量3 | 全色+欠色 | マナ総量がちょうど3のカードで固め、軽減・強化・サーチを受ける | 三角の祭壇、三位一体の像、三つ葉の導き | 特定コスト指定 |
| 孤高 | 全色 | 同名カードを1枚ずつにしたデッキ(ハイランダー)で強くなる | 孤高の聖騎士、千の書架、孤高の王 | ハイランダー構築 |
| 「星詠み」 | 白青 | 名前に「星詠み」を含むカード同士で探し合い、出るたびに引く | 星詠みの巫女、星詠みの天文台、星詠みの銀河 | 遊戯王のテーマ |
| 「鉄機」 | 欠色+赤 | アーティファクトを並べ、機巧(3つ以上)と共鳴で大型を出す | 鉄機の司令塔、鉄機竜、鉄機王 | 遊戯王のテーマ、MTGの金属術・親和 |
| 墓地 | 黒青緑 | 自分の墓地を増やして深淵(7枚以上)を満たす。再演で使い回す。相手のライブラリーを削って勝つ道も | 骨の巨像、墓地の王、記憶の葬列 | MTGのスレッショルド・フラッシュバック・切削 |
| 生け贄 | 黒赤(白) | 自分のクリーチャーを生け贄に捧げ、死亡したときの能力でじわじわ削る | 悪魔崇拝者、魂の焼却炉、死の舞踏 | MTGのアリストクラッツ |
| ライフ | 白黒(緑) | ライフを得るたびにカウンターを置いたり相手のライフを減らしたりする | 癒しの侍祭、血の契約、天上の歌姫 | MTGのライフゲイン |
| カウンター | 緑白黒 | +1/+1カウンターで育てる。不屈で除去に強い | 群れの成長、不屈の守り手、成長し続ける芽 | MTGの+1/+1カウンター・頑強 |
| 呪文 | 青赤 | インスタントとソーサリーを唱えるたびに強化・ダメージ・ドロー | 渦の大魔術師、炎嵐の魔導師、呪文書の写本 | MTGの果敢・スペルスリンガー |
| 装備 | 欠色+白赤 | 装備品をクリーチャーにつけて押す | 英雄の剣、武装の達人、鍛冶師の弟子 | MTGの装備品 |
| 鼓動 | 緑赤 | マナゾーンにカードが置かれるたびに得をする。マナゾーンの色の数も数える | 地脈の聖騎士、鼓動の炎、七色の獣 | MTGの上陸・版図 |
| マナ武装 | 単色 | 同じ色のカードをマナゾーンに貯めるほど強くなる | 武装の聖騎士、炎の大竜、大地の主 | デュエマのマナ武装 |
| 部族 | 各色 | ゴブリン・エルフ・ゾンビ・騎士・ウィザード・マーフォーク・ドラゴン | ゴブリンの頭目、エルフの大族長、ゾンビの王 | MTGの部族 |
| 派生キーワード | 各色 | 既存キーワードの強化版・派生版(天翔、大威迫、吸血、疾駆、鉄壁、輪廻、烈燃、略奪、満開、奈落、伏兵)を持つカード | 雲海の王、恐怖の化身、輪廻の大樹、マナ喰らいの王 | MTGのダッシュ・頑強など |

## スターターデッキ

`cards/build.mjs` が自動で組みます。テーマのセットのカードを優先し、残りを除去とクリーチャーで埋めます。テーマデッキには、自分のクリーチャーも巻き込む全体除去は入れません。

| デッキ | 色 |
|---|---|
| 2色の汎用デッキ×10 | 2色の組み合わせすべて(最初の166種類が中心) |
| 人間:民衆の蜂起 | 白赤 |
| エンチャント:星座の祝福 | 緑白 |
| マナ総量3:三刻の盟約 | 白青+欠色 |
| 孤高:三色の独唱 | 黒赤緑(40種類すべて1枚ずつ) |
| 星詠み:天球の導き | 白青 |
| 鉄機:鋼の軍団 | 赤+欠色 |
| 墓地:深淵の書庫 | 青黒 |
| 生け贄:血の宴 | 黒赤 |
| ライフ:命の循環 | 白黒 |
| カウンター:不屈の大地 | 黒緑 |
| 呪文:嵐の詠唱 | 青赤 |
| 装備:武具の行進 | 赤白 |
| 鼓動:大地の脈動 | 赤緑 |
| マナ武装:赤単の烈火 / 緑単の巨獣 | 赤 / 緑 |
| 部族:ゴブリン / エルフ / ゾンビ | 赤 / 緑 / 黒 |
