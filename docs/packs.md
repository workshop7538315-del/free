# パック(第n弾)

カードは「第n弾」のパックで管理します。それぞれのパックには固有の名前と、デザインの元になる**3つの単語**があります。
デッキビルダーの「パック」で絞り込むと、そのパックに収録されたカード(再録を含む)だけが出ます。カードの下には収録パックが、強化パックのカードには元のカードが表示されます。

## パックの種類

| 種類 | 中身 |
|---|---|
| **新規展開** | 新しいアーキタイプ・キーワード・シナジー |
| **既存カード強化** | 既存カードの再録、強化版、リメイク、サポート。既存のアーキタイプを立て直し、昔のカードに新しい使い道を与える |

既存カード強化パックの新しいカードは、必ず元のカードとの関係を持ちます。

| 関係 | 意味 |
|---|---|
| 強化版 | 元のカードの上位互換(同じ役割で少し強い) |
| リメイク | 元のカードの考え方を、別の形で作り直したもの |
| サポート | 元のカードやそのアーキタイプを支えるもの |

### 第4弾「紋章の目覚め」

3つの単語「大地・刻印・目覚め」から、**マナゾーン(大地)に置いたカードに刻まれた力が目を覚ます**というテーマにしました。

- **紋章**:そのカードがマナゾーンにあるあいだだけ働く能力。戦場では働かない。「どのカードをマナにするか」がそのまま戦略になる。
- **顕現 N**:自分のマナゾーンからマナ総量N以下のクリーチャー・カードを戦場に出す。マナにしたカードを後から呼び戻せる。
- 既存の輪廻(死ぬとマナゾーンへ)、還元、略奪、鼓動と組み合わさる。相手の紋章カードは侵食・略奪の良い的になる。
- 40種類:各色6、多色7、欠色3。スターターデッキ「紋章:大地の目覚め(緑白)」「紋章:顕現の潮(緑青)」を追加。

### 第5弾「再燃の炎」

3つの単語「再燃・鍛錬・継承」から、**弱かったアーキタイプを再び燃え上がらせ(再燃)、カードを鍛え直し(鍛錬)、元のカードの役割を受け継ぐ(継承)**パックにしました。

- 強化版10種類(例:大火花の小鬼 ← 火花の小鬼、英雄の聖剣 ← 英雄の剣)
- リメイク8種類(例:炎の呪文砕き ← 呪文砕き、鉄機の量産工場 ← 鉄機の量産)
- サポート12種類(例:鍛冶の聖火 → 装備、エルフの集い → エルフ)
- 再録10種類(火花の礫、激昂した戦士、渦の大魔術師 など)。再録カードは同じIDのまま、収録パックに第5弾が加わる。

### 第6弾「宮廷の暗闘」

3つの単語「貴族・陰謀・決闘」から、**宮廷の表では貴族が剣を抜いて決闘し、裏では陰謀が相手の手札と戦力を削る**パックにしました。「暗闘」は表に出ない争いのことで、陰謀と決闘をひとつにした名前です。

- **決闘**:自分のクリーチャーと相手のクリーチャーが互いにパワー分のダメージを与え合う(格闘の発展形)。**先制攻撃を持つ側が先に斬る**ので、白と赤の先制攻撃持ちが決闘に強い。相手だけが倒れたら「勝ち」で、勝ったときの効果や「決闘に勝つたび」が起こる。
- **陰謀 ―**:このターン、相手がカードを捨てたか、相手のクリーチャーが戦場を離れたなら有効。手札破壊・除去・バウンスのあとに、終了ステップで引く・削る。
- **貴族**:新しい種族。各色にいて、白百合の公爵・宮廷の女王・三家の盟約が他の貴族を強くし、王家の印章が貴族を軽くする。
- 既存カードとの組み合わせ:接死(決闘用の細剣)、第5弾の先制攻撃カード、装備、侵食・略奪以外の除去全般、生け贄(相手のクリーチャーが離れると陰謀が満たされる)。
- 40種類:白6・青5・黒6・赤6・緑6・多色8・欠色3。スターターデッキ「決闘:剣と薔薇の作法(赤白)」「陰謀:影の宮廷(青黒)」を追加。

### 第7弾「虚無の胎動」

テーマは「虚無」。**すべて欠色のカード**で、色を奪い、色を捨て、何もないところから力を得るパックです。

- **虚無**(種族・呪文の種類):コストに {C}(画面では「◇」)を持ち、欠色マナでなければ唱えられない。`node cards/build.mjs` は、虚無のカードが {C} を持ち色マナ記号を持たないことを検査する。第3弾の「嚥下する虚無」(旧名:略奪する虚無)「マナ喰らいの王」もこの種族。
- **略奪の変更**:相手のマナゾーンのカードを**裏向き(欠色)**にして自分のマナゾーンに置く。相手のマナが減るので、9マナ以上の大型と始祖だけが持つ。
- **嚥下 N**(エルドラージの嚥下が元):相手の**ライブラリー**の上からN枚を裏向きで自分のマナに置く。相手のマナは減らない。第3弾・第7弾の中型の略奪カードはすべて嚥下に変えた(第4弾の紋章喰らいは「相手の紋章を1枚裏向きにする」に変更)。
- **始祖**(エムラクールなどエルドラージの始祖が元):万象を呑むもの(12マナ)、色彩を喰らう始祖(13マナ)、終わりなき虚無(15マナ)。「唱えたとき」に略奪し、**虚食**(裏向きのカード1枚につき{1}軽くなる)で出す。墓地に置かれると墓地をライブラリーに戻すので、墓地から踏み倒せない。
- **落とし子**:虚無の群体が出す0/1のトークン。生け贄に捧げると欠色マナを出す。
- **虚化 N**:自分のマナゾーンのカードをN枚と、相手のマナゾーンのカードをN枚、自分が選んで裏向きにする。自分は色を捨てて虚空・真空に近づき、相手は色や紋章を失う。
- **虚空 ―**(マナゾーンの半分以上が欠色)/**真空 ―**(すべて欠色):欠色が多いほど強くなる。「欠色を喰らうもの」は欠色のカードの枚数だけ強くなる。
- 40種類:虚無ではない道具7種類(欠色マナを出すアーティファクト、虚化、虚無を探すカード)と、虚無33種類。
- スターターデッキ「虚無:色喰らいの深淵(欠色)」(除去のコントロール)、「虚無:群れなす虚無(欠色)」(ドローンを並べて虚無の門で強化)、「虚無:始祖の目覚め(欠色)」(嚥下で裏向きのマナを増やし、始祖を出す)を追加。

### 第8弾「逆襲の烽火」

総当たり戦で苦戦したデッキ(装備・呪文・生け贄・赤白・緑系・エルフ・カウンター)に、**そのデッキでしか働かないエンジン**を配る強化パックです。紋章のようにどのデッキにも入る「汎用の出張セット」を作らないことを一番の条件にしました。

- 上位のデッキはドローを10〜14枚持ち、飛行で攻めます。弱いデッキ(赤・緑)はドローがほぼ0で、飛行に触れません。そこで、ドローは**条件つき**(装備品が出るたび、呪文を2つ唱えたら、2体で攻撃したら、パワー4以上が出るたび、エルフが出るたび、マナ武装)にし、緑には**飛行にだけ当たる**除去(空裂きの蔦、樹上の弓兵、大地揺らしの継承竜)を入れました。
- **強襲 ―**:このターン2体以上で攻撃したなら。**連唱 ―**:このターン呪文を2つ以上唱えたなら。
- **生成**:カードリストにないカードを手札に加える(DCGの仕組み)。《火の粉》《簡易の剣》など。チャージはできない。
- **効果が2つ以上あるカード**と、**モード呪文**(「次から1つを選ぶ」)を初めて入れました。強いエンジンには「1ターンに1回だけ誘発する」をつけています。
- 76種類すべてに元のカード(強化版・リメイク・サポート)があり、再録は8種類。

### 第9弾「秘蔵の門」

遊戯王のEXデッキ、デュエル・マスターズの超次元ゾーンを参考にした**秘蔵庫**のパックです。

- デッキはメイン40枚と、**秘蔵庫8枚まで**(同名2枚まで)。秘蔵庫にはリリース召喚を持つクリーチャーだけが入る。
- **リリース召喚 N(素材)**:素材に書かれたパーマネント(神獣=エンチャントかクリーチャー、祖霊=エンチャント、機神=アーティファクト、種類なし=なんでも)か**奉納**を持つものを、マナ総量の合計がN以上になるように生け贄に捧げ、秘蔵庫からコストなしで出す(1ターンに1回)。戦場を離れると秘蔵庫に戻る。
- **奉納 N(種類)**:リリースのときだけマナ総量+N。種類つき(神獣・祖霊・機神)はその種類を出すときだけ。エンチャントにもクリーチャーにもある。
- 軽いエンチャント(1〜2マナ)は、それだけでドロー・マナ・占術・ライフを生む。**残して使い続けるか、捧げて秘蔵庫を開くか**を選ぶパックです。自分を生け贄に捧げて効果を出すエンチャント(祖霊の墓碑、叡智の燭台、歯車の祭壇)もあります。
- 《供物の灯》({1} エンチャント 奉納 1)を生成するカードで、手札を減らさずに素材を用意できる。
- 秘蔵庫のクリーチャーは17種類(神獣4・祖霊4・機神4・種類なし5)。「出るたびに除去」が繰り返されると強すぎるため、戦場に出たときの除去は持たせず、体と攻撃時・死亡時の能力に力を寄せました。
- スターターデッキ「秘蔵:神獣の森(緑白)」「秘蔵:灯る祖霊(白黒)」「秘蔵:目覚める機神(青赤)」を追加。

### 第9.5弾「仮面劇場の狂宴」

イタリアの即興仮面劇(コンメディア・デッラルテ)を舞台にした、**青・黒・赤だけ**のパックです。秘蔵庫からの新しい出し方「エントラータ」を入れました。

- **喝采【狂気】【悲劇】【喜劇】**:観客の喝采。【狂気】は青か赤の呪文を唱えるたび、【悲劇】は黒か赤のものを生け贄に捧げるかクリーチャーが死亡するたび、【喜劇】は赤か白のクリーチャー2体以上で攻撃したときに溜まる。加護の枠(5つ)を使う。
- 秘蔵庫に役者を入れるだけで使える**どのデッキにも足せる強化**です。青・黒・赤・白のデッキが、メインを変えずに強くなります。溜まり方を色で決めているので、それ以外の色(緑)には効きません。
- **エントラータ N【〜】**:喝采をN消費して秘蔵庫から役者を出す。回数の制限はなく、軽い役者を溜めてから一気に出せる。【悲劇】の重い役者は、クリーチャーを素材にしたリリース召喚でも出せる。
- **ウシータ**(退場):役者が秘蔵庫に戻るとき。
- 役者はコンメディア・デッラルテの決まった役柄(アルレッキーノ、ブリゲッラ、スカラムーシュ、ドットーレ、インナモラーティ、プルチネッラ、カピターノ、コロンビーナ、パンタローネ)。
- 45種類:秘蔵庫の役者13種類、メイン32種類。スターターデッキ「喝采:狂気の道化芝居(青赤)」「喝采:血の悲劇(黒赤)」「喝采:喜劇の一座(赤白)」を追加。

### 第9.5弾「黄金郷の発明家」

開拓・発明・黄金郷をテーマにした、**白・赤・緑と欠色だけ**のパックです。喝采が効かない緑に、秘蔵庫に入れるだけで使える強化を用意しました。

- **開拓進化【緑】N**:緑のクリーチャーを素材に、**マナゾーンのカード**をマナ総量の合計N以上ぶん墓地に置いて、秘蔵庫の開拓者を出す。戦場のカードも使えるとリリース召喚の上位互換になるため、マナゾーンだけにした。
- **紋章 ― 埋蔵 N**:マナゾーンから開拓に使うとき、マナ総量に+N。重いカードや、チャージ時・紋章を持つカードを入れ、「何をマナに置くか」が開拓の強さになるようにした。チャージ時の効果は「開拓者をコントロールしているなら」に絞り、どの緑デッキにも入る出張カードにならないようにしている。
- **切り札《黄金郷の大開拓者 エル・ドラード》**:大開拓進化【緑】(開拓者の上に重ね、3枚以上)。出たとき加護《黄金郷への道》を得て、以後の開拓進化はライブラリーの上を削って払える。加護は、初めて実装した仕組み。
- **組み立て【白】【赤】と武装進化**:白か赤のクリーチャーをタップして、秘蔵庫の発明品(装備品)を組み立てる。条件(装備したクリーチャーが攻撃した、装備品が2つ以上)を満たすと、秘蔵庫の合体先と武装進化する。合体先が離れると、発明品も一緒に秘蔵庫に戻る。
- **《黄金》**:開拓・発明の報酬として生成される{0}のアーティファクト。生け贄に捧げて好きな色のマナを1つ出す。
- 54種類:秘蔵庫13種類(開拓者5、発明品4、合体先4)、メイン41種類(埋蔵を持つカード9種類を後から追加)。スターターデッキ「黄金郷:開拓者の進軍(緑単)」「黄金郷:発明家の工房(赤白)」を追加。緑の7デッキ(赤緑・緑白・エルフ・緑単の巨獣・紋章2つ・鼓動)の秘蔵庫に開拓者を、鉄機と決闘の秘蔵庫に発明品を入れた。

## データの管理

| 場所 | 内容 |
|---|---|
| `cards/packs.mjs` | パックの一覧(ID、番号、名前、種類、3つの単語、テーマ、収録セット、再録) |
| `cards/sets/p4-awakening.mjs` など | パックのカード |
| `cards/packs.json` | `build.mjs` が作るパックの一覧(アプリが読む) |
| `cards/cards.json` の `pack` / `packs` / `basedOn` | カードが初めて収録されたパック / 再録を含むすべてのパック / 元のカードとの関係 |

`node cards/build.mjs` は次をチェックします:弾の番号が1から連番か、種類が正しいか、3つの単語があるか、同じカードが2つのパックで新規収録されていないか、再録するカードが存在するか、既存カード強化パックの新規カードがすべて元のカードを持っているか、元のカードが存在するか。

**カードIDは変えません。** 保存済みのデッキはカードIDで記録しているので、パックが増えても今のデッキはそのまま使えます。

## 次のパックの作り方

1. 3つの単語から、パックの名前・種類(新規展開か既存カード強化か)・テーマを決める。
2. `cards/sets/p8-○○.mjs` にカードを書く。強化パックなら `basedOn(card, 元のID, "強化版" | "リメイク" | "サポート")` で包み、再録は ID の配列で書く。
3. `cards/packs.mjs` の `PACKS` に追加する。新しいアーキタイプならスターターデッキを `build.mjs` に足す。
4. `node cards/build.mjs` → `cd app && npm run simulate -- 2000` → `npm run tier` でエラーと勝率の偏りを確かめる。

## 第7弾を入れたあとのバランス(総当たり 16,830戦)

| デッキ | 勝率 |

欠色だけのデッキは色の事故がなく、虚空・真空がいつも満たされるので、最初は勝率66〜84%と強すぎました。略奪の数とコスト、虚空・真空で増えるパワー、除去のコストを下げて中位に合わせました。緑に虚無を混ぜるデッキも試しましたが、緑マナと欠色マナの両方が必要になって安定せず(勝率20%前後)、スターターには入れていません。虚化は、相手のマナの色や紋章を消しながら、色のデッキに虚無を混ぜる道具として使えます。虚化が相手のマナも裏向きにするようになってからは、毎ターン虚化する「裏返しの儀式」が相手の色を封じきってしまうため、戦場に出たときの1回だけにしました。

## 略奪の見直し(ランデス・エルドラージの研究をもとに)

MTGのランデスやデュエル・マスターズのマナ破壊、エルドラージの扱いを調べ、次の方針で直しました。

- 相手のマナを減らす効果は「相手が何もできない試合」を生むので、重く・少なくする。→ 略奪は9マナ以上の大型と始祖だけ。中型は嚥下(相手のライブラリーから奪う)に。
- 規制すべきは強いカードではなく、早く出す加速(エルドラージの冬)。→ チャージ時の連鎖を止め、「チャージ時にライブラリーの一番上をマナに置く」古老の樹・地脈の探索者は「自分のマナが相手の枚数以下なら」に。
- 大型には「唱えたとき」の能力と、墓地から踏み倒されないための「墓地をライブラリーに戻す」能力を持たせる(エムラクールが元)。

| 試したこと | 直す前 | 直した後 |
|---|---|---|
| ご提示の略奪デッキ(緑の加速+虚無の大型) | 勝率78%、ターン4で相手のマナが0に | 約49%、相手のマナが0になる試合はほぼなし |
| 緑の加速+緑の大型(虚無なし) | 77.6% | 47.6% |
| 虚無:始祖の目覚め(新) | ― | 54.2% (A)。始祖はおよそ8ターン目(最速5〜6ターン目)に出る |
| 虚無:色喰らいの深淵 | 57.8% | 52.9% (B) |
| 虚無:群れなす虚無 | 52.9% | 47.5% (B) |

## ランデスデッキの検証(ルールは変えない)

侵食(虚空の裂け目)と略奪の始祖を組み合わせたランデスデッキを検証しました。

- CPUが使うと勝率は約30%。勝った試合の多くは、相手のマナが少ないまま動けずに負けた試合(ランデスを使わないデッキでは1〜4%)。勝つときはロック、という偏った形。
- 一方で、星詠みや、墓地の枚数で零式を使う墓地デッキ(侵食すると相手の墓地が増える)、速いデッキには負ける。

ロックを減らすルールも2つ試しましたが、どちらも採用しませんでした。

| 試したルール | ロックで勝った試合 | ランデスデッキの勝率 | 採用しない理由 |
|---|---|---|---|
| なし(今のまま) | 28% | 29.5% | ― |
| マナを失ったら次のターンに追加でチャージ | 26% | 27.1% | このゲームではマナは手札から置くので、ランデスが「相手の手札を1枚減らす」効果(ハンデス)に変わってしまう。ロックもほとんど減らない |
| 侵食・略奪でマナを4枚より少なくできない | 19% | 21.0% | ロックは少し減るが、デッキが弱くなるだけでランデスらしさも薄れる |

ランデスは強すぎず、はっきりした弱点もあるので、「勝つときはロック」という性格のまま残します。根刻の精4枚の追加チャージや、刻印の渦と呪文書の写本の軽減の重ねがけも単独で試しましたが、勝率は53%と13%で壊れてはいませんでした。
