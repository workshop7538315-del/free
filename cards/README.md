# カードデータの書式

全カードは [`cards.json`](cards.json) に配列で書きます。デッキビルダー(`app/`)はこのファイルを読み込みます。

```json
{
  "id": "r001",
  "name": "火花の小鬼",
  "cost": "{R}",
  "type": "クリーチャー",
  "subtype": "ゴブリン",
  "power": 1,
  "toughness": 1,
  "rarity": "コモン",
  "text": ["速攻", "チャージ時 ― 対戦相手1人を対象とする。火花の小鬼はそのプレイヤーに1点のダメージを与える。"],
  "flavor": "(任意)"
}
```

## 項目

| 項目 | 必須 | 内容 |
|---|---|---|
| id | ○ | 一意なID。色の頭文字(w/u/b/r/g/c=欠色/m=多色)+3桁の番号。**一度決めたら変えない**(保存済みデッキがIDで参照するため) |
| name | ○ | カード名 |
| cost | ○ | MTG表記のマナコスト。{W}{U}{B}{R}{G}{C}、数字、{X}、混成 {W/U}、単色混成 {2/W}。コストなしは空文字 |
| type | ○ | クリーチャー、インスタント、ソーサリー、エンチャント、アーティファクト、アーティファクト・クリーチャー など |
| subtype | | 種族などのサブタイプ |
| power / toughness | | クリーチャーのみ |
| rarity | ○ | コモン/アンコモン/レア/神話レア |
| text | ○ | ルール文章。1段落ずつ配列に。キーワードは [docs/keywords.md](../docs/keywords.md) の表記に従う |
| flavor | | フレーバーテキスト |

## 色は書かない

カードの色はマナコストから自動で決まります([docs/rules.md](../docs/rules.md) 5.5)。

- 色マナ記号が1色 → 単色
- 2色以上(混成を含む)→ 多色
- 色マナ記号なし → 欠色
