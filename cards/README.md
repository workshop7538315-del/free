# カードデータの書式

カードは色ごとのファイルにまとめて書きます(例:`cards/red.md`)。1枚ごとに次の書式を使います。

```
### カード名
- コスト:{2}{R}
- 色:赤
- タイプ:クリーチャー ― ゴブリン
- P/T:2/2
- レアリティ:コモン
- テキスト:
  - 速攻
  - チャージ時 ― 対戦相手1人に1点のダメージを与える。
- フレーバー:(任意)
```

## 項目

| 項目 | 内容 |
|---|---|
| コスト | MTG表記。{W}{U}{B}{R}{G}{C} と数字 |
| 色 | 白/青/黒/赤/緑/欠色/多色(色名を併記) |
| タイプ | クリーチャー、インスタント、ソーサリー、エンチャント、アーティファクト。クリーチャーは「―」のあとに種族 |
| P/T | クリーチャーのみ |
| レアリティ | コモン/アンコモン/レア/神話レア |
| テキスト | キーワードは [docs/keywords.md](../docs/keywords.md) の表記に従う |

## ファイル一覧(予定)

- `white.md` / `blue.md` / `black.md` / `red.md` / `green.md`
- `colorless.md`(欠色)
- `multicolor.md`(多色)
