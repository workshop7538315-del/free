# オリジナルカードゲーム(タイトル未定)

MTGをベースにした2人対戦のトレーディングカードゲームです。
土地カードは存在せず、デュエル・マスターズのように**手札のどのカードでもマナにできる**のが最大の特徴です。

## コンセプト

- クリーチャーで殴り合い、呪文で干渉する、MTGらしい対戦。
- 土地がないので、マナ事故(土地が来ない・来すぎる)が起きない。
- デッキの全カードが「戦力」にも「資源」にもなる。毎ターン「どのカードをマナに置くか」が悩みどころ。
- 色は **白(W)・青(U)・黒(B)・赤(R)・緑(G)** の5色と、**欠色(無色)**、**多色**。

## 遊ぶ

**https://workshop7538315-del.github.io/free/**

- **デッキを組む**:540種類のカードからデッキを組み、Supabaseに保存できます(未ログインならブラウザ内に保存)。色・タイプ・キーワード・アーキタイプ・数値で絞り込めます。
- **対戦する**:CPUと対戦できます。自分で組んだ40枚のデッキか、28種類のスターターデッキ(2色の汎用10種+アーキタイプ18種)を使えます。ルールの処理(マナの支払い、戦闘、効果)は自動です。

手元で動かす場合や Supabase の設定は [app/README.md](app/README.md) を見てください。

```bash
cd app && npm install && npm run dev
```

## カードの内訳

| 色 | 種類 |
|---|---|
| 白 | 90 |
| 青 | 70 |
| 黒 | 82 |
| 赤 | 83 |
| 緑 | 82 |
| 欠色 | 55 |
| 多色(混成・3色以上を含む) | 78 |
| **合計** | **540** |

アーキタイプは人間・エンチャント・マナ総量3・孤高(ハイランダー)・「星詠み」・「鉄機」・墓地・生け贄・ライフ・カウンター・呪文・装備・鼓動・マナ武装・部族の15種類です。さらに、既存のキーワードの強化版・派生版(天翔、大威迫、吸血、疾駆、鉄壁、輪廻、烈燃、略奪、満開、奈落、伏兵)を持つカードが40種類あります。詳しくは [docs/archetypes.md](docs/archetypes.md)。
