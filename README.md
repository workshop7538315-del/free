# オリジナルカードゲーム(タイトル未定)

MTGをベースにした2人対戦のトレーディングカードゲームです。
土地カードは存在せず、デュエル・マスターズのように**手札のどのカードでもマナにできる**のが最大の特徴です。

## コンセプト

- クリーチャーで殴り合い、呪文で干渉する、MTGらしい対戦。
- 土地がないので、マナ事故(土地が来ない・来すぎる)が起きない。
- デッキの全カードが「戦力」にも「資源」にもなる。毎ターン「どのカードをマナに置くか」が悩みどころ。
- 色は **白(W)・青(U)・黒(B)・赤(R)・緑(G)** の5色と、**欠色(無色)**、**多色**。

## デッキビルダー

[`app/`](app/) にデッキを組んで保存できるWebアプリがあります。保存先は Supabase です(未設定ならブラウザ内に保存)。動かし方と Supabase の設定は [app/README.md](app/README.md) を見てください。

```bash
cd app && npm install && npm run dev
```
